# Spatial Tutor AI

1. Immersive Spatial Learning Environments

Textbooks and standard videos struggle to teach subjects that are inherently spatial, like human anatomy, architectural history, or complex molecules.

The Problem: Students are forced to learn 3D concepts through 2D media, leading to a disconnect in understanding scale and spatial relationships.

The Hack: A lightweight web application that renders highly realistic 3D environments or objects. As the student navigates through the 3D space, an integrated AI tutor tracks their coordinates or viewpoint. If a student clicks on a specific structural element or cell component, the AI provides contextual, real-time explanations about exactly what they are looking at.

Why it wins: Rendering advanced 3D models smoothly in a web browser is a great technical flex. It shows judges you can combine modern graphics pipelines (like 3D Gaussian Splatting via lightweight web frameworks) with LLM context awareness.
